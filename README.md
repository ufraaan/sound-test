# Sound Test

A simple sound test website. Use it to check your audio setup.

## What it does

- Test left/right channels
- Check if your speakers are in phase
- Measure mic volume
- Run frequency sweeps

## How to use

Open index.html in your browser. Click the buttons to run tests.

## Tech

Just HTML, CSS, and vanilla JS. No frameworks or anything.
